2. DATA PROCESSING AND PURPOSES
---------------------------------

2.1 Required data

Legal basis: Art. 6(1)(b) GDPR (performance of a contract)

The following data is processed to provide the app and to perform license
management:

  - License key, stored as a SHA-256 hash
    → for license verification and activation

  - In-game name and Wizard ID
    → from locally imported account file, used solely to assign
      support requests

  - Activation timestamp
    → to document the start of the license period

2.2 Data for abuse prevention

Legal basis: Art. 6(1)(f) GDPR (legitimate interests)

The following data is processed to ensure proper use of the software and to
prevent license abuse:

  - Device fingerprint, stored as a SHA-256 hash
    (derived from MAC address, computer name, operating system and architecture)

  - Timestamp of the last program start

The legitimate interest consists in protecting the software against unauthorized
use. Processing is strictly purpose-bound and does not involve profiling.

The device fingerprint is stored in hashed form only; recovery of the original
values is not intended.

2.3 Optional statistics

Legal basis: Art. 6(1)(a) GDPR (consent)

Only upon explicit consent:

  - App version
  - UI language

This data is evaluated in anonymized form only and is not used for
identification purposes.

Consent can be withdrawn at any time within the app.
Already collected data can be deleted.


3. OBLIGATION TO PROVIDE DATA
-------------------------------

Providing required data is necessary to use the app.

Without this data:

  - license verification is not possible
  - use of the software is not possible


4. AUTOMATED DECISIONS
------------------------

Automated processes are used for license verification.

This may result in:

  - licenses being activated or rejected
  - usage being restricted in the event of abuse

However, no automated decision-making within the meaning of Art. 22 GDPR
with legal effects or significant impact takes place.


5. DATA SECURITY
-----------------

Appropriate technical and organizational measures pursuant to Art. 32 GDPR
are implemented to protect your data.

These include in particular:

  - encrypted data transmission (TLS/HTTPS)
  - storage of sensitive data in hashed form only (SHA-256)
  - access restrictions at server level


6. STORAGE LOCATION AND DATA PROCESSING
-----------------------------------------

Local:
  - Settings and license data in the user directory
    (%APPDATA%\SWTO)

Server:
  - Supabase (backend service)
  - Hosted via Amazon Web Services (AWS)
  - Region: eu-west-1 (Ireland, EU)

Processing is carried out under a data processing agreement pursuant to
Art. 28 GDPR.

AWS may be engaged as a sub-processor.

Third-country transfer:
AWS is a provider based in the United States.

It cannot be excluded that data may be transferred to the United States.

To ensure an adequate level of data protection, appropriate safeguards pursuant
to Art. 46 GDPR are in place, in particular EU Standard Contractual Clauses.


7. RETENTION PERIOD
---------------------

  - Trial licenses:
    Deletion 14 days after expiry

  - Full licenses:
    Retained until deletion or upon request

  - Statistics data:
    Retained until consent is withdrawn


8. DATA SHARING
----------------

Data is not shared with third parties.

Exception:
  - technical service providers (Supabase, AWS) within the framework of GDPR

You have the following rights:
