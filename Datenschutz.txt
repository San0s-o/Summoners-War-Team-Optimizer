2. WELCHE DATEN WERDEN VERARBEITET?
-------------------------------------

2.1 Pflichtdaten

a) Rechtsgrundlage: Vertragserfüllung (Art. 6 Abs. 1 lit. b DSGVO)
Diese Daten werden zur Bereitstellung der App und zur Durchführung des
Lizenzverhältnisses verarbeitet:

  - Lizenzschlüssel, gespeichert als SHA-256-Hash
    → zur Lizenzprüfung und Freischaltung der Software

  - Ingame-Name und Wizard-ID
    → diese Daten werden aus der vom Nutzer lokal importierten Account-Datei
      ausgelesen und ausschließlich zur Zuordnung bei Supportanfragen verwendet

  - Aktivierungszeitpunkt
    → zur Nachvollziehbarkeit des Lizenzbeginns, insbesondere bei Trial-Lizenzen

b) Rechtsgrundlage: Berechtigtes Interesse (Art. 6 Abs. 1 lit. f DSGVO)
Das berechtigte Interesse besteht im Schutz vor Lizenzmissbrauch und in der
Sicherstellung der vereinbarungsgemäßen Einzelnutzung der Software.

  - Gerätefingerabdruck, gespeichert als SHA-256-Hash
    (abgeleitet aus MAC-Adresse, Computername, Betriebssystem und Architektur)
    → zur Gerätebindung der Lizenz und zur Verhinderung unbefugter Mehrfachnutzung

    Der Gerätefingerabdruck wird ausschließlich in gehashter Form gespeichert.
    Ein unmittelbarer Klartextabruf der Ausgangswerte ist daraus nicht vorgesehen.

  - Zeitstempel des letzten Programmstarts
    → zur Erkennung missbräuchlicher Nutzung und zur Überprüfung des Lizenzstatus

2.2 Optionale Statistikdaten
Rechtsgrundlage: Einwilligung (Art. 6 Abs. 1 lit. a DSGVO)

Diese Daten werden nur verarbeitet, wenn du ausdrücklich zugestimmt hast:

  - App-Version
    → technische Versionsstatistik

  - UI-Sprache
    → Nutzungsstatistik nach Sprachregion

Diese Daten werden nicht zur persönlichen Identifikation verwendet.

Die Einwilligung kann jederzeit in den Einstellungen der App widerrufen werden.
Bereits erhobene optionale Daten können über Einstellungen → „Daten löschen“
vom Server entfernt werden.


3. SPEICHERORT UND SPEICHERDAUER
---------------------------------

Speicherort:
- Lokal auf deinem Gerät:
  Lizenzdatei und Einstellungen im Benutzerverzeichnis
  (%APPDATA%\SWTO\)

- Serverseitig:
  Supabase, Hosting über Amazon Web Services (AWS),
  Region eu-west-1 (Irland, EU)

Speicherdauer:
- Trial-Lizenzdaten:
  Werden automatisch 14 Tage nach Ablauf des Trial-Zeitraums gelöscht,
  sofern für dasselbe Gerät kein neuer gültiger Lizenzschlüssel registriert
  wurde. Die Löschung umfasst den Lizenzeintrag, Aktivierungsdaten und
  Sitzungstoken.

- Full-Lizenzdaten:
  Werden gespeichert, solange der zugehörige Lizenzeintrag verwaltet wird,
  und bei Entfernung des Lizenzeintrags oder nach Bearbeitung einer
  berechtigten Löschanfrage gelöscht.

- Optionale Statistikdaten:
  Werden bis zum Widerruf der Einwilligung gespeichert und sind auf Anfrage
  oder über die Funktion „Daten löschen“ jederzeit entfernbar.

Zur Geltendmachung deines Löschrechts kannst du den Verantwortlichen über
Discord oder GitHub-Issues kontaktieren.

2. WHAT DATA IS PROCESSED?
----------------------------

2.1 Required data

a) Legal basis: performance of a contract (Art. 6(1)(b) GDPR)
This data is processed to provide the app and to perform the license agreement:

  - License key, stored as a SHA-256 hash
    → for license verification and software activation

  - In-game name and Wizard ID
    → this data is read from the account file imported locally by the user
      and is used solely to assign support requests

  - Activation timestamp
    → to document the start of the license period, especially for trial licenses

b) Legal basis: legitimate interests (Art. 6(1)(f) GDPR)
The legitimate interest consists in protecting against license abuse and
ensuring the agreed single-device use of the software.

  - Device fingerprint, stored as a SHA-256 hash
    (derived from MAC address, computer name, operating system and architecture)
    → for device binding of the license and prevention of unauthorized
      multi-device use

    The device fingerprint is stored in hashed form only.
    Direct retrieval of the underlying plain-text values is not intended.

  - Timestamp of the last program start
    → for detection of abusive use and verification of license status

2.2 Optional statistics
Legal basis: consent (Art. 6(1)(a) GDPR)

This data is only processed if you have given explicit consent:

  - App version
    → technical version statistics

  - UI language
    → usage statistics by language region

This data is not used for personal identification.

Consent can be withdrawn at any time in the app settings.
Already collected optional data can be removed from the server via
Settings → "Delete data".


3. STORAGE LOCATION AND RETENTION
-----------------------------------

Storage location:
- Locally on your device:
  license file and settings in the user directory
  (%APPDATA%\SWTO\)

- Server-side:
  Supabase, hosted via Amazon Web Services (AWS),
  region eu-west-1 (Ireland, EU)

Retention period:
- Trial license data:
  Automatically deleted 14 days after the end of the trial period,
  provided that no new valid license key has been registered for the same
  device. Deletion includes the license record, activation data and session
  tokens.

- Full license data:
  Retained as long as the corresponding license record is being administered,
  and deleted when the license record is removed or after a valid erasure
  request has been processed.

- Optional statistics:
  Retained until consent is withdrawn and removable at any time upon request
  or through the “Delete data” function.

To exercise your right to erasure, you may contact the controller via Discord
or GitHub Issues.
